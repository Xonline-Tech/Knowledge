- ### 1. 确保宿主机加载了 WireGuard 内核模块
  
  NetBird 默认依赖内核级 WireGuard 来保证高性能。Alpine 默认可能没有加载 `wireguard` 模块。
  
  **在 Alpine 宿主机上执行：**

  <!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!---->
  
  <!----><!---->
  
  <!---->
  
  ```
  # 加载 wireguard 内核模块
  sudo modprobe wireguard
  
  # 设置开机自动加载
  echo "wireguard" | sudo tee -a /etc/modules
  ```

  *(如果 Alpine 没有 `wireguard` 模块，需通过 `apk add wireguard-tools` 或更新 Alpine 内核版本)*
- ### 2. 确保  `/dev/net/tun`  设备可用
  
  Alpine 默认可能不会自动挂载 TUN 设备，而 WireGuard 建立虚拟网卡（`wt0`）必须依赖它。
  
  **检查与创建：**
  
  <!----><!----><!----><!----><!----><!----><!----><!---->
  
  <!---->
  
  Bash
  
  <!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!---->
  
  <!----><!---->
  
  <!---->
  
  ```
  # 检查是否存在 tun 设备
  ls -l /dev/net/tun
  
  # 如果不存在，手动创建并赋予权限
  sudo mkdir -p /dev/net
  sudo mknod /dev/net/tun c 10 200
  sudo chmod 0666 /dev/net/tun
  ```

- ### 3. Docker 启动参数修改（重点）
  
  在 Alpine 宿主机上运行 NetBird 容器时，为了避免 eBPF Proxy 和 WireGuard 初始化失败（比如之前出现的超时或权限拒绝问题），**强烈建议加上额外的 Cap 能力与 设备挂载**。<!---->  <!----><!----><!----><!----><!----><!----><!----><!---->
- #### 方案 A：使用  `docker run`
  
  相比官方的默认命令，建议增加 `--device /dev/net/tun` 以及权限控制：
  
  <!----><!----><!----><!----><!----><!----><!----><!---->
  
  <!---->
  
  Bash
  
  <!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!---->
  
  <!----><!---->
  
  <!---->
  
  ```
  docker run -d --name netbird-agent \
  --network host \
  --cap-add=NET_ADMIN \
  --cap-add=SYS_ADMIN \
  --cap-add=SYS_RESOURCE \
  --cap-add=NET_RAW \
  --device /dev/net/tun:/dev/net/tun \
  -e NB_SETUP_KEY="<YOUR_SETUP_KEY>" \
  -e NB_MANAGEMENT_URL="https://netbird.xon.ink:443" \
  -v netbird-client:/var/lib/netbird \
  netbirdio/netbird:latest
  ```
  
  <!---->

- #### 方案 B：使用  `docker-compose.yml` （推荐）
  <!----><!----><!----><!----><!----><!----><!----><!---->
  
  <!---->
  
  YAML
  
  <!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!----><!---->
  
  <!----><!---->
  
  <!---->
  
  ```
  version: '3.8'
  
  services:
  netbird:
    image: netbirdio/netbird:latest
    container_name: netbird-agent
    network_mode: host
    cap_add:
      - NET_ADMIN
      - SYS_ADMIN
      - SYS_RESOURCE
      - NET_RAW
    devices:
      - /dev/net/tun:/dev/net/tun
    environment:
      - NB_SETUP_KEY=<YOUR_SETUP_KEY>
      - NB_MANAGEMENT_URL=https://netbird.xon.ink:443
    volumes:
      - netbird-client:/var/lib/netbird
    restart: unless-stopped
  
  volumes:
  netbird-client:
  ```
